用 Cloudflare Pages 零成本搭一个静态博客

2026-02-13 · 技术 / Cloudflare

你现在看到的这个博客，就是我照着本文的流程搭出来的：纯静态 HTML/CSS/JS，托管在 Cloudflare Pages 上，绑定自己的域名，总花费 0 元，没有服务器要维护，也没有对象存储账单要担心。

为什么选 Pages

  • 免费额度够用：静态托管不限流量（合理使用范围内），个人博客随便造；
  • 自带 CDN 和 HTTPS：全球节点分发，证书自动签发续期；
  • 绑定域名方便：域名 NS 托管在 Cloudflare 的话，自定义域一键生效，DNS 记录自动创建；
  • 没有后端依赖：不用数据库、不用对象存储，一堆 HTML 文件就是全部家当。

第一步：写静态文件

目录结构非常简单：

blog/
├── index.html          # 首页（文章列表）
├── posts.json          # 文章清单（标题/日期/摘要/链接）
├── about.html
├── assets/
│   ├── style.css
│   └── main.js
└── posts/
    └── hello-world.html

首页通过 fetch('/posts.json') 渲染文章卡片，所以以后每写一篇新文章，只需要往 posts/ 丢一个 HTML 文件，再往 posts.json 加一条记录，不需要任何构建工具。

第二步：部署到 Pages

安装并登录 Wrangler（Cloudflare 官方 CLI），然后一条命令：

npx wrangler pages deploy ./blog --project-name=blog

首次运行会自动创建 Pages 项目并发布，完成后会得到一个 https://blog.pages.dev 的地址，这时候博客已经上线了。

第三步：绑定自己的域名

前提是你的域名已经用 Cloudflare 做 DNS 解析（NS 指向 Cloudflare）。然后调一下 API 把子域绑到 Pages 项目上：

curl -X POST \
  "https://api.cloudflare.com/client/v4/accounts/<ACCOUNT_ID>/pages/projects/blog/domains" \
  -H "Authorization: Bearer <TOKEN>" \
  -H "Content-Type: application/json" \
  --data '{"name":"blog.example.com"}'

Cloudflare 会自动帮你创建 CNAME 记录并签发证书，等一两分钟，https://blog.example.com 就通了。

以后的更新流程

  1. 在 posts/ 里写一篇新 HTML；
  2. 在 posts.json 里登记；
  3. 再跑一遍 wrangler pages deploy。

整个过程不到一分钟。没有 npm install，没有构建缓存玄学，没有半夜爬起来修服务器。

工具的意义是让你专注于内容本身。当你不再需要维护博客系统，博客才可能活得久一点。
